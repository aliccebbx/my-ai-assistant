ИИ-помощник по уборке и домашним делам
ИИ-агент помогает планировать уборку и решать бытовые задачи с учётом времени, доступных инструментов и требований безопасности. Он использует модель GigaChat-2 через внешний API.

О проекте
ИИнтеллектуальный помощник по уборке и домашним делам — это консольный ИИ-агент, созданный для того, чтобы помогать пользователю поддерживать порядок дома и удобнее организовывать повседневные бытовые задачи.

Агент работает на основе модели GigaChat-2 через API. Пользователь описывает, что нужно сделать, какую комнату или зону привести в порядок, сколько времени есть и какие ограничения необходимо учитывать. На основе этой информации помощник предлагает подходящие рекомендации и помогает разбить большую уборку на понятные действия.

Главная идея проекта — сделать домашние дела более организованными: не тратить время на раздумья, с чего начать, учитывать реальные условия и постепенно справляться с задачами.

Для чего нужен агент
Помощник ориентирован на следующие задачи:

Планирование уборки. Помогает составить последовательность действий для уборки комнаты или отдельной зоны.
Организация домашних дел. Подсказывает, как распределить бытовые задачи и не пытаться сделать всё одновременно.
Уборка с ограниченным временем. Помогает подобрать реалистичный объём работы, если на уборку есть, например, 15, 30 или 60 минут.
Учет условий. Принимает во внимание наличие или отсутствие бытовой техники, доступных средств и другие ограничения, о которых сообщает пользователь.
Организация пространства. Предлагает идеи для хранения вещей и поддержания порядка.
Уточнение задачи. Если информации недостаточно, сначала задаёт вопросы, чтобы не предлагать неподходящий план.
Как работает ИИ-агент
Пользователь запускает программу и описывает бытовую задачу.
Агент анализирует запрос с помощью модели GigaChat-2.
Если не хватает информации, помощник задаёт уточняющие вопросы.
После уточнения агент предлагает краткие рекомендации или пошаговый план.
Пользователь может продолжить диалог и уточнить детали.
Агент специализируется именно на уборке, домашних делах, планировании быта и организации пространства. На запросы по другим темам он сообщает о своей специализации и предлагает вернуться к бытовым задачам.

Примеры запросов
Можно обратиться к помощнику, например, так:

«Помоги убрать мою комнату за 30 минут».
«Составь план генеральной уборки кухни».
«Как организовать хранение одежды в небольшом шкафу?»
«Мне нужно разобрать рабочий стол, но у меня мало времени. С чего начать?»
«Составь график домашних дел на неделю».
Чем точнее пользователь описывает помещение, задачу, доступное время и ограничения, тем полезнее будет рекомендация.

Особенности проекта
Общение с ИИ на русском языке.
Системный промпт задаёт специализацию и правила поведения агента.
Помощник старается отвечать кратко и по существу.
Пустые сообщения не отправляются в API.
История диалога ограничена двумя последними парами сообщений, чтобы сохранять актуальный контекст.
История переписки записывается в локальный файл chat_history.txt.
Предусмотрены команды для управления диалогом: очистка истории, просмотр её структуры и завершение программы.

Python 3.8 или новее.

Установка
Откройте терминал в папке УП01/AI-Agent и выполните:

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
Для Windows PowerShell активация окружения:

.\\.venv\\Scripts\\Activate.ps1
.\.venv\Scripts\Activate.ps1
Настройка
Скопируйте шаблон конфигурации:

cp .env.example .env
Откройте локальный файл .env и укажите собственные значения переменных:

GIGACHAT_CREDENTIALS — учётные данные GigaChat API.
GIGACHAT_SCOPE — область доступа API.
Не публикуйте файл .env, реальные ключи и пароли. Корневой .gitignore исключает .env из Git.

Запуск
Из папки проекта при активированном виртуальном окружении:

python main.py
Команды агента
очистить — очистить историю текущего диалога.
история — показать роли сообщений в текущей истории.
выход — завершить программу.
Пустой ввод не отправляется в API: программа просит ввести текст сообщения.

Ограничения
Агент предоставляет текстовые рекомендации и планы. Он не выполняет уборку физически, не управляет бытовой техникой и не проверяет состояние помещения самостоятельно. Результат зависит от информации, которую сообщает пользователь. При использовании бытовой химии необходимо соблюдать инструкции производителя и не смешивать чистящие средства.
