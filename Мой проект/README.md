# ИИ-помощник по уборке и домашним делам

Агент помогает планировать уборку и решать бытовые задачи с учётом
ограничений пользователя: времени, доступных инструментов, требований
к безопасности. Он предлагает конкретный алгоритм под задачу, а не
общие рекомендации.

## Структура проекта

- `main.py` — точка входа (основная версия программы).
- `prompts.py` — системный промпт (`SYSTEM_PROMPT`).
- `requirements.txt` — зависимости.
- `.env.example` — образец переменных окружения без секретов.
- `certs/russian_trusted_root_ca_pem.crt` — корневой CA-сертификат.

## Установка

python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
