# ИИ-помощник по уборке и домашним делам

## Назначение

Проект помогает составлять планы уборки и решать бытовые задачи. Для генерации ответов используется модель GigaChat-2 через внешний API.

## Файлы проекта

- `main.py` — короткая версия запуска агента.
- `prompts.py` — системные инструкции для модели.
- `tests.txt` — примеры предыдущих проверок.
- `requirements.txt` — сторонние Python-библиотеки.
- `.env.example` — пример переменных окружения без секретных значений.
- `certs/russian_trusted_root_ca_pem.crt` — сертификат для HTTPS-соединения.
- `Мой проект/main.py` и `Мой проект/prompts.py` — дополнительная расширенная версия.

В репозитории присутствуют две версии программы. Перед окончательной сдачей нужно определить, какую из них считать основной.

## Требования

- Python 3.
- Доступ в интернет.
- Учётные данные для GigaChat API.

Точная версия Python и версии пакетов пока не зафиксированы: их нужно проверить в рабочем окружении.

## Установка

Откройте терминал в папке `Мой проект` и выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

Для Windows PowerShell создание и активация окружения выполняются командами:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
```

## Настройка

1. Скопируйте `.env.example` в файл `.env`.
2. Заполните `GIGACHAT_CREDENTIALS` и `GIGACHAT_SCOPE` своими значениями.
3. Не отправляйте настоящий `.env` в GitHub и не публикуйте ключи.

## Запуск

Для короткой версии из папки `Мой проект`:

```bash
python3 main.py
```

Для расширенной версии из той же папки:

```bash
python3 "Мой проект/main.py"
```

Команды установки и запуска добавлены как инструкция, но пока не проверены на компьютере пользователя. В обоих файлах запуска обнаружено написание `credenticals` в параметре клиента GigaChat. Перед запуском нужно сверить имя параметра с установленной версией библиотеки; успешная работа API пока не подтверждена.

## Ограничения

- Для ответа требуется доступ к внешнему API GigaChat.
- Ответы модели могут содержать неточности; их нужно проверять.
- В `tests.txt` есть старые примеры ответов. Они не подтверждают работу текущей версии программы.
