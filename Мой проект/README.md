# Архив прежней структуры проекта

Основная актуальная версия ИИ-агента находится в папке [УП01/AI-Agent](../УП01/AI-Agent).

Для установки, настройки и запуска используйте README в этой папке. Материалы, учебные задания и исторические файлы, оставшиеся здесь, сохранены как архив и не являются точкой входа актуального проекта.

Не размещайте в репозитории реальные ключи API, пароли, локальный файл `.env` или виртуальное окружение `.venv`.
