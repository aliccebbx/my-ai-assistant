# Техническое заключение

## 1. Сведения о проекте

- **Название:** ИИ-помощник по уборке и домашним делам.
- **Назначение:** помощь в планировании уборки и решении бытовых задач.
- **Репозиторий:** https://github.com/aliccebbx/my-ai-assistant
- **Дата анализа:** 18.11.2026.

## 2. Результаты инвентаризации

В проекте есть две версии программы на Python. Для генерации ответов используется GigaChat-2 через библиотеку `gigachat`, для загрузки настроек — `python-dotenv`. В коде также используется стандартный модуль `os` и CA-сертификат.
Созданы README.md, requirements.txt, .env.example. Версии зафиксированы:
Python 3.8.13, gigachat 0.2.3, python-dotenv 1.0.1.

## 3. Диагностика

Запуск выполнен фактически 18.11.2026 (сначала из рабочей папки,
затем из итоговой УП01/AI-Agent). Подключение к GigaChat API
подтверждено: агент отвечает на запросы.

По проверкам:

- запуск программы — пройден (старт без ошибок);
- обычный запрос — пройден (план уборки по теме и ограничениям);
- уточнение данных — пройден (агент запрашивает недостающие детали);
- пустой ввод и ввод из пробелов — пройден (запрос обрабатывается
  локально, в API не уходит);
- команды «очистить», «история», «выход» — пройдены;
- посторонний вопрос — пройден (агент обозначил границы темы).

## 4. Документация

Созданы пять документов третьего дня: инвентаризация, проверка зависимостей, аудит документации, результаты тестирования и техническое заключение.

## 5. Риски

| Риск | Возможное последствие | Статус и действие |
|---|---|---|
| Опечатка credenticals | Ошибка подключения | Закрыт: сверено, в основной версии credentials=key |
| Нет проверки пустого ввода | Пустой запрос уйдёт в API | Закрыт: обработка локальная, подтверждено проверками 6–7 |
| Две версии программы | Запуск не той версии | Закрыт: основная выбрана и перенесена в УП01/AI-Agent/main.py |
| Версии пакетов не зафиксированы | Проблемы совместимости | Закрыт: gigachat==0.2.3, python-dotenv==1.0.1 |
| Сохранённые диалоги в репозитории | Публикация личных данных | Закрыт: chat_history.txt проверен, личных данных нет; из публикации исключён |
| Небезопасный совет при мытье окон | Риск травмы | Открыт: агент предлагает «встать на широкий устойчивый стул»; дополнить prompts.py запретом, повторить проверку |
| Файлы, опубликованные ранее | Секреты в истории коммитов | Открыт: проверить git ls-files перед сдачей |

## 6. Итоговый статус

Работоспособность подтверждена. Программа запускается, подключается
к GigaChat API и проходит все проверки сценариев. Основная версия
выбрана и перенесена в требуемую структуру УП01/AI-Agent.
