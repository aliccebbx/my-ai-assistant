# Проверка зависимостей

## Среда выполнения

- **ОС:** не установлена по содержимому GitHub; требуется проверить на компьютере, где запускается проект.
- **Версия Python:** не установлена. Проверить командой `python3 --version` (macOS/Linux) или `py --version` (Windows).
- **Виртуальное окружение:** наличие `.venv` по GitHub не подтверждено; виртуальное окружение не должно загружаться в репозиторий.
- **Файл зависимостей:** `requirements.txt` в просмотренном дереве репозитория отсутствует.
- **Проверка установки:** команды установки и `pip show` на компьютере пользователя не выполнялись в рамках проверки GitHub.

## Обнаруженные расхождения

1. В исходниках используются сторонние пакеты `gigachat` и `python-dotenv`, но `requirements.txt` в репозитории не найден.
2. Точные версии библиотек нельзя подтвердить только по операторам `import`.
3. Версия Python и список фактически установленных пакетов не проверены.
4. В корневом и вложенном вариантах проекта используются разные наборы импортов: расширенный вариант дополнительно импортирует `ChatModelOptions`.

## Исправления и оставшиеся проблемы

На момент подготовки документа зависимости не устанавливались и версии не подбирались, чтобы не указывать неподтверждённые значения.

После проверки на компьютере, где находится рабочая среда, выполнить:

```bash
python3 --version
python3 -m pip show gigachat
python3 -m pip show python-dotenv
```

Для Windows вместо `python3` можно использовать `py`.

После получения фактических версий создать `requirements.txt` с двумя используемыми сторонними пакетами и зафиксировать проверенные версии. Не использовать полный вывод `pip freeze` без проверки, так как он может содержать лишние пакеты.

**Статус:** проверка состава импортов выполнена по исходному коду; версии, установка и совместимость пакетов требуют проверки в рабочем окружении.
