# Проверка зависимостей

## Среда выполнения

- **ОС:** Linux (WSL).
- **Python:** версия Python 3.8.13
- **Виртуальное окружение:** .venv создано в папке проекта.
- **Файл зависимостей:** `Мой проект/requirements.txt`.
- **Проверка установки:** выполнены команды pip install numpy и pip show numpy. Пакет numpy версии 1.26.4 установлен.

## Реестр библиотек

| Имя          | Тип                        | Для чего используется                 | Версия   |
|--------------|----------------------------|---------------------------------------|----------|
| os           | Стандартная библиотека     | Чтение переменных окружения           | С Python |
| gigachat     | Внешний пакет              | Клиент GigaChat и структуры запроса   | 0.2.3    |
