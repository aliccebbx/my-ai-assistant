# Проверка зависимостей

## Среда выполнения

- **ОС:** не проверена на компьютере пользователя.
- **Python:** версия не установлена; проверить командой `python3 --version` (macOS/Linux) или `py --version` (Windows).
- **Виртуальное окружение:** наличие локального `.venv` по GitHub определить нельзя.
- **Файл зависимостей:** добавлен `Мой проект/requirements.txt`.
- **Проверка установки:** команды установки и `pip show` пока не выполнялись на компьютере пользователя.

## Реестр библиотек

| Имя | Тип | Для чего используется | Версия |
|---|---|---|---|
| `os` | Стандартная библиотека Python | Чтение переменных окружения | Поставляется с Python |
| `gigachat` | Внешний пакет | Клиент GigaChat и структуры запроса | Не проверена |
| `python-dotenv` | Внешний пакет | Загрузка настроек из `.env` | Не проверена |
| `prompts` | Локальный модуль | Системный промпт | Не применяется |

## Обнаруженные расхождения

1. В исходниках используются `gigachat` и `python-dotenv`.
2. Файл `requirements.txt` добавлен с этими двумя пакетами, но точные версии пока не указаны.
3. Версия Python и список установленных пакетов не проверены.
4. В расширенной версии дополнительно импортируется `ChatModelOptions`.

## Что нужно проверить на компьютере

В терминале из папки проекта выполнить:

```bash
python3 --version
python3 -m pip show gigachat
python3 -m pip show python-dotenv
```

На Windows вместо `python3` можно использовать `py`.

После проверки нужно записать фактические версии в `requirements.txt`. Не следует указывать версии наугад.

**Статус:** состав библиотек определён по импортам; установка, версии и совместимость пока не проверены.
