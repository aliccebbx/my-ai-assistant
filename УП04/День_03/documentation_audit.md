# Аудит документации

## Проверка README.md

В просмотренном дереве GitHub-репозитория файл `README.md` не обнаружен. Поэтому проверить существующую инструкцию запуска и подтвердить её соответствие проекту пока невозможно.

В репозитории обнаружены:
- исходники `main.py` и `prompts.py`;
- файл с записями проверок `tests.txt`;
- сертификат в папке `certs`;
- дополнительная вложенная копия приложения и сохранённые примеры запросов/ответов.

## Какие сведения отсутствовали или устарели

1. Нет `README.md` с назначением проекта, требованиями, настройкой API, установкой зависимостей и запуском.
2. Нет `requirements.txt` с перечнем внешних библиотек.
3. Не определено, какая копия программы является основной: `Мой проект/main.py` или `Мой проект/Мой проект/main.py`.
4. В обоих просмотренных файлах запуска аргумент клиента записан как `credenticals=key`. Вероятна опечатка; правильное имя параметра необходимо сверить с установленной версией библиотеки GigaChat.
5. В корневом `main.py` после `strip()` нет проверки пустого ввода, хотя системный промпт требует не отправлять пустой запрос модели.
6. В обеих копиях используется относительный путь к сертификату. При запуске из другой рабочей папки файл может не найтись.
7. В расширенной копии сохраняются запрос и ответ в текстовые файлы. Для публичного репозитория следует исключить попадание личных данных в эти файлы.

## Какие изменения внесены

Созданы документы инвентаризации и проверки зависимостей в папке `УП04/День_03`. В них описаны фактически обнаруженные файлы, компоненты, внешние настройки и неустановленные сведения.

Исходный код не изменялся. README и requirements.txt не создавались в рамках этого аудита, потому что фактические версии пакетов и рабочая команда запуска не подтверждены на компьютере пользователя.

## Какие команды реально проверены

Команды установки пакетов и запуска приложения на локальном компьютере не выполнялись. Нельзя утверждать, что подключение к GigaChat API прошло успешно.

Для следующей проверки нужно выполнить команды из каталога выбранной версии проекта:

```bash
python3 --version
python3 -m pip show gigachat
python3 -m pip show python-dotenv
python3 main.py
```

На Windows можно использовать `py` вместо `python3`.

## Можно ли запустить проект по инструкции

Подтвердить запуск по README нельзя: README отсутствует. По исходникам видно, что программа ожидает переменные окружения `GIGACHAT_CREDENTIALS` и `GIGACHAT_SCOPE`, пакет GigaChat и сертификат. До фактического запуска остаются вопросы к имени аргумента авторизации и наличию настроек.
