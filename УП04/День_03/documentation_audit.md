# Аудит документации

## Проверка README.md

В папке `Мой проект` создан `README.md`. В нём указаны назначение программы, файлы проекта, зависимости, настройка переменных окружения, команды установки и запуска, а также ограничения.

Инструкция пока не проверена фактическим запуском на компьютере пользователя.

## Какие сведения отсутствовали или устарели

1. Изначально не было README с описанием и запуском программы.
2. Не было `requirements.txt`.
3. В проекте есть две версии программы, основная пока не выбрана.
4. В обоих файлах запуска указано `credenticals=key`. Вероятно, это опечатка; параметр нужно сверить с установленной версией GigaChat SDK.
5. В короткой версии нет отдельной проверки пустого ввода до отправки запроса.
6. В коде используется относительный путь к сертификату, поэтому важно запускать программу из правильной папки.
7. В расширенной версии сохраняются запросы и ответы в текстовые файлы.

## Какие изменения внесены

- Добавлен `Мой проект/README.md`.
- Добавлен `Мой проект/requirements.txt` с пакетами `gigachat` и `python-dotenv`. Точные версии будут указаны после проверки среды.
- Добавлен `Мой проект/.env.example` без секретных значений.
- В корне репозитория добавлен `.gitignore` для исключения секретов, виртуального окружения, кэша и логов.
- Исходный код пока не изменялся.

## Какие команды реально проверены

Команды установки, запуска и подключения к GigaChat API на компьютере пользователя не выполнялись. Команды в README являются инструкцией, а не подтверждённым результатом запуска.

Для проверки нужно выполнить:

```bash
python3 --version
python3 -m pip show gigachat
python3 -m pip show python-dotenv
python3 main.py
```

## Можно ли запустить проект по инструкции

README содержит необходимые начальные шаги, но запуск пока не подтверждён. Нужно проверить версии библиотек, заполнить локальный файл `.env` и сверить имя параметра авторизации в вызове GigaChat.

- Выбрать основную версию программы.
- Проверить параметр авторизации GigaChat и исправить его, если опечатка подтвердится.
- Добавить проверку пустого ввода в короткую версию.
- Проверить запуск и ответы API.
- Зафиксировать реальные версии пакетов в `requirements.txt`.
- Перенести проект в требуемую папку `УП01/AI-Agent`.
- Проверить файлы с сохранёнными запросами и ответами на личные данные.
