# Инвентаризация ИИ-агента

## 1. Паспорт проекта

- **Название:** ИИ-помощник по уборке и домашним делам.
- **Назначение:** помогать планировать уборку и решать бытовые задачи с учётом ограничений пользователя.
- **Основные функции:** рекомендации по уборке, уточнение недостаточных данных, учёт времени и бытовых ограничений, отказ от вопросов вне темы.
- **Файл запуска:** основная версия `УП01/AI-Agent/main.py`; вспомогательные и исторические файлы сохранены отдельно.
- **Язык:** Python.
- **Версия Python:** 3.8.13 (проверено командой python3 --version).
- **Дата анализа:** 18.11.2026.

## 2. ИИ-компоненты

- **Модель:** GigaChat-2.
- **Поставщик:** GigaChat, внешний API.
- **Библиотека:** gigachat 0.2.3 (проверено pip show).
- **Загрузка настроек:** python-dotenv 1.0.1 (проверено pip show).
- **Промпты:** prompts.py (системный промпт SYSTEM_PROMPT).

## 5. Внешние сервисы и настройки

- Программа обращается к GigaChat через библиотеку `gigachat`.
- Используются переменные `GIGACHAT_CREDENTIALS` и `GIGACHAT_SCOPE`.
- Для соединения указан файл CA-сертификата.
- Файл `.env.example` размещён в `УП01/AI-Agent` как образец без секретов. Настоящие значения ключей в него помещать нельзя.

## 7. Проверка безопасности

- .gitignore содержит исключения для .env, .venv/, __pycache__/,
  *.pyc, *.log — проверено cat .gitignore.
- .env на диске есть, в репозиторий не публиковать (исключён
  .gitignore). Создать .env.example без секретных значений.
- chat_history.txt проверен (head): тестовые диалоги об уборке,
  личных данных нет; файл истории из публикации исключить.
- .gitignore не удаляет файлы, опубликованные ранее: перед сдачей
  проверить историю коммитов через git ls-files, чтобы .env
  не остался в предыдущих версиях.
