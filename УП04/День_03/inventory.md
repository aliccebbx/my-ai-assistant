# Инвентаризация ИИ-агента

## 1. Паспорт проекта

- **Название:** ИИ-помощник по уборке и домашним делам.
- **Назначение:** помогать планировать уборку и решать бытовые задачи с учётом ограничений пользователя.
- **Основные функции:** рекомендации по уборке, уточнение недостаточных данных, учёт времени и бытовых ограничений, отказ от вопросов вне темы.
- **Файл запуска:** есть две версии — короткая `Мой проект/main.py` и расширенная `Мой проект/Мой проект/main.py`.
- **Язык:** Python.
- **Версия Python:** не установлена; требуется проверить в рабочем окружении.
- **Дата анализа:** 19.11.2026.

## 2. ИИ-компоненты

- **Модель:** GigaChat-2.
- **Поставщик:** GigaChat, внешний API.
- **Библиотека:** `gigachat`.
- **Загрузка настроек:** `python-dotenv`.
- **Промпты:** `prompts.py` в каждой из двух версий проекта.
- **Дополнительные инструменты и базы данных:** в просмотренном коде не обнаружены.

## 3. Реестр компонентов

| Компонент | Назначение | Статус |
|---|---|---|
| Python | Среда выполнения | Версия не проверена |
| GigaChat-2 | Генерация ответов | Указана в коде |
| GigaChat API | Подключение к модели | Указан в коде |
| `gigachat` | Библиотека клиента | Версия не проверена |
| `python-dotenv` | Загрузка настроек | Версия не проверена |
| `os` | Работа с переменными окружения | Стандартная библиотека |
| `prompts.py` | Системные инструкции | Собственный модуль |
| CA-сертификат | HTTPS-соединение | Файл есть в проекте |

| Путь | Назначение |

## 5. Внешние сервисы и настройки

- Программа обращается к GigaChat через библиотеку `gigachat`.
- Используются переменные `GIGACHAT_CREDENTIALS` и `GIGACHAT_SCOPE`.
- Для соединения указан файл CA-сертификата.
- Файл `.env.example` добавлен как образец. Настоящие значения ключей в него помещать нельзя.

## 6. Неустановленные сведения

- Версия Python и установленные версии библиотек.
- Успешность подключения к GigaChat API.
- Какая версия программы будет основной.
- Проверка запуска после переноса проекта в итоговую структуру.

## 7. Проверка безопасности

- В корне репозитория добавлен `.gitignore` с исключениями для `.env`, виртуального окружения, кэша и логов.
- Добавлен `.env.example` без секретных значений.
- Файл `.env` в просмотренных путях GitHub не обнаружен.
- В репозитории остаются файлы с примерами диалогов и запросов. Перед сдачей нужно убедиться, что в них нет личной или конфиденциальной информации.
- `.gitignore` не удаляет файлы, которые уже были опубликованы ранее.
