## Обнаруженные ошибки

### 1. Проверка пустого ввода — закрыта 18.11.2026
В короткой версии не было проверки пустого ввода до отправки запроса.
Проверено запуском "main_day13.py" 18.11.2026: пустой ввод и ввод из одних
пробелов обрабатываются локально («Введите текст сообщения.»), запрос в API
не уходит, программа не падает. Замечание устранено в актуальной версии.

### 2. Параметр подключения к SDK — закрыт 18.11.2026
Опечатка "credenticals" встречалась в черновиках и ранних версиях кода.
Сверено с сигнатурой установленной библиотеки gigachat 0.2.3:
корректное имя параметра — "credentials". В файле "main_day13.py"
(основная версия) параметр указан верно: "credentials=key".
Подключение к API подтверждено фактическим запуском: агент получает
ответы модели.

### 3. Небезопасный совет при мытье окон — открыт
В проверке 3 от 18.11.2026 агент предложил «встать на широкий устойчивый
стул» для мытья снаружи. Вставать на стул и стулья — риск падения и травмы.
Требуется дополнить системный промпт ("prompts.py") запретом на вставание
на стулья, подоконники и высовывание из окна; вместо этого — телескопическая
швабра с безопасной стороны, магнитные щётки или обращение к специалистам.
В тестовых примерах (tests.txt) заменить похожие рекомендации.

### 4. Качество ответа о стерильной чистоте — открыт (низкий приоритет)
В ответе присутствует разговорная формулировка «взаимоисключающие параграфы»,
а горячая вода не гарантирует дезинфекцию. Рекомендуется уточнить промпт:
не обещать стерильность, предлагать влажную уборку и проветривание.
