# Развёртывание ИИ-агента

- **Название:** ИИ-помощник по уборке и домашним делам.
- **Репозиторий:** https://github.com/aliccebbx/my-ai-assistant
- **Ветка:** `main`.
- **Папка проекта:** `УП01/AI-Agent`.
- **Основной файл:** `main.py`.
- **Системный промпт:** `prompts.py`.
- **Способ переноса:** клонирование репозитория через Git в Ubuntu Server.
- **Планируемый путь:** `~/projects/my-ai-assistant/УП01/AI-Agent`.

## Проверка исходных файлов

**Проверено по GitHub:**

- репозиторий и ветка доступны;
- основной файл `main.py` присутствует;
- файл `prompts.py` присутствует;
- `requirements.txt` содержит `gigachat==0.2.3` и `python-dotenv==1.0.1`;
- CA-сертификат присутствует;
- точка входа использует GigaChat-2 через внешний API;
- в коде используются переменные `GIGACHAT_CREDENTIALS` и `GIGACHAT_SCOPE`.

## Команды переноса в Ubuntu

```bash
mkdir -p ~/projects
cd ~/projects
git clone https://github.com/aliccebbx/my-ai-assistant.git
cd my-ai-assistant
cd УП01/AI-Agent
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Перед запуском необходимо безопасно задать переменные GigaChat. Не загружать действующие ключи в репозиторий.
