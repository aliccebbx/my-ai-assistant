# Развёртывание ИИ-агента

- **Название агента:** ИИ-помощник по уборке и домашним делам.
- **Ссылка на GitHub:** https://github.com/aliccebbx/my-ai-assistant
- **Способ переноса:** планируется `git clone` внутри Ubuntu Server.
- **Папка проекта в репозитории:** `Мой проект`.
- **Планируемый путь в Ubuntu:** `~/projects/my-ai-assistant/Мой проект`.
- **Файл запуска:** `main.py`.
- **Команда запуска:** `python main.py` из папки проекта после активации `.venv` и настройки переменных окружения. Запуск пока не проверен.

## Подготовка проекта

Команды выполняются в Ubuntu Server:

```bash
mkdir -p ~/projects
cd ~/projects
git clone https://github.com/aliccebbx/my-ai-assistant.git
cd my-ai-assistant
ls -la
cd "Мой проект"
ls -la
```

Затем нужно создать новое виртуальное окружение в Ubuntu, установить зависимости из `requirements.txt` и настроить переменные GigaChat по фактической инструкции проекта.
