# Среда эксплуатации

## Целевая система

- **Целевая ОС:** Ubuntu Server 24.04.
- **Статус проверки Ubuntu:** удалённая виртуальная машина не подключена; фактические параметры ОС, пользователя, сети и IP не подтверждены.
- **Python и Git в Ubuntu:** версии не подтверждены.
- **Путь проекта в Ubuntu:** планируемый — `~/projects/my-ai-assistant/Мой проект`.

## Параметры, которые нужно получить непосредственно в Ubuntu

После входа в виртуальную машину выполнить:

```bash
lsb_release -a
whoami
python3 --version
git --version
ip -br a
ping -c 4 github.com
```

Эти команды относятся к целевой Ubuntu-среде и не могут быть подтверждены проверкой GitHub.
