# Проверка GPU

## Анализ требований проекта

**Проверено по исходному коду и зависимостям репозитория.**

- Агент обращается к модели `GigaChat-2` через библиотеку `gigachat`.
- В проекте не обнаружена локальная загрузка или запуск весов нейросетевой модели.
- В `requirements.txt` указаны `gigachat==0.2.3` и `python-dotenv==1.0.1`.
- Следовательно, вычисления нейросетевой модели выполняются внешним сервисом GigaChat API, а не на GPU виртуальной машины пользователя.

## Команды аппаратной проверки в Ubuntu

Для проверки графических устройств:

```bash
lspci | grep -Ei "vga|3d|display"
```

Для проверки NVIDIA:

```bash
nvidia-smi
```

**Статус аппаратной проверки:** команды подготовлены, но их вывод в Ubuntu Server не получен. Поэтому наличие или отсутствие GPU в виртуальной машине не подтверждено.

## Вывод

Для текущей архитектуры ИИ-агента отдельный вычислительный GPU не является обязательным условием: проект использует внешний GigaChat API. Для работы необходимы интернет, установленные Python-зависимости и корректные учётные данные API. Фактическое обнаружение видеоустройства в Ubuntu остаётся аппаратной проверкой на виртуальной машине.
