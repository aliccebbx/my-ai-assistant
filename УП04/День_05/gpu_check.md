# Проверка GPU

## Анализ требований проекта

**Проверено по исходному коду и зависимостям репозитория.**

- Агент обращается к модели `GigaChat-2` через библиотеку `gigachat`.
- В проекте не обнаружена локальная загрузка или запуск весов нейросетевой модели.
- В `requirements.txt` указаны `gigachat==0.2.3` и `python-dotenv==1.0.1`.
- Следовательно, вычисления нейросетевой модели выполняются внешним сервисом GigaChat API, а не на GPU виртуальной машины пользователя.

## Команды аппаратной проверки в Ubuntu

Для проверки графических устройств:

```bash
lspci | grep -Ei "vga|3d|display"
```

Для проверки NVIDIA:

```bash
nvidia-smi
```

## Вывод

Параметр и Значение

Доступен ли вычислительный GPU: Нет — в виртуальной машине только эмулированный видеоадаптер без поддержки CUDA.
Требуется ли GPU моему агенту: Нет.
Обоснование: Агент работает через внешний GigaChat API: инференс модели выполняется на стороне сервиса. Для работы необходимы интернет, установленные Python-зависимости и корректные учётные данные API.

## Заключение 
Aппаратная проверка выполнена в полном объёме. Отсутствие вычислительного GPU не является ограничением для данного проекта: архитектура агента изначально рассчитана на работу с облачным API. Среда эксплуатации соответствует требованиям проекта.
