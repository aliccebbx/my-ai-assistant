# Проверка GPU

## Проверка графического устройства

Команда для Ubuntu Server:

```bash
lspci | grep -Ei "vga|3d|display"
```

**Результат:** не выполнено. Вывод команды нужно добавить после проверки.

## Проверка NVIDIA

Команда:

```bash
nvidia-smi
```

**Результат:** не выполнено. Если команда отсутствует, это само по себе не доказывает отсутствие видеокарты.

## Нужен ли GPU агенту

По текущей структуре проект использует модель GigaChat-2 через внешний GigaChat API и библиотеку `gigachat`. Локальное выполнение нейросетевой модели в проекте не описано. Поэтому отдельный вычислительный GPU в виртуальной машине, как правило, не требуется: вычисления выполняются на стороне внешнего сервиса.

**Вывод:** отсутствие GPU не должно мешать работе агента при наличии интернета, корректных настроек доступа к GigaChat API и установленных зависимостей. Фактическую доступность графического устройства в Ubuntu ещё нужно проверить.
