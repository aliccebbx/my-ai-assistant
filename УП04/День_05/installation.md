## Установка в Ubuntu Server

Для выполнения установки в целевой системе предусмотрены команды:

```bash
sudo apt update
sudo apt install -y git python3 python3-pip python3-venv
git --version
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip check
```

**Статус:** команды подготовлены и проверены как инструкция. Фактическое выполнение в Ubuntu Server и вывод `pip check` подтверждены

## Настройка конфигурации

Программа использует переменные окружения:

- `GIGACHAT_CREDENTIALS`;
- `GIGACHAT_SCOPE`.

Реальные значения нельзя публиковать в GitHub, отчётах или скриншотах. Файл `.env` должен оставаться локальным и быть исключён из Git.
